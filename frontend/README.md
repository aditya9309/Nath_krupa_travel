# Nath Krupa Travels - Frontend

React frontend for Nath Krupa Travels booking platform with Tailwind CSS and GSAP animations.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

The app will run on `http://localhost:5174`

## Features

- Modern, responsive UI with Tailwind CSS
- GSAP animations throughout
- React Router for navigation
- Protected routes (user & admin)
- Form validation
- Toast notifications
- Image uploads
- Multi-passenger booking form

## Project Structure

- `src/components/` - Reusable components (Navbar, Footer, PrivateRoute, etc.)
- `src/pages/` - Page components (Home, Packages, Dashboard, etc.)
- `src/context/` - React Context (AuthContext)
- `src/utils/` - Utilities (API client)
